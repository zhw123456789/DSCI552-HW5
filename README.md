# DSCI 552 Homework 5

Install dependencies with `python -m pip install -r requirements.txt`.
Open `notebook/Zhang_Hanwen_HW5.ipynb` and run all cells from the notebook directory.
The required data are included in `data/` and loaded using relative paths.

On macOS, XGBoost may also require `brew install libomp`.

Data sources: [Acute Inflammations](https://archive.ics.uci.edu/dataset/184/acute+inflammations) and [Communities and Crime](https://archive.ics.uci.edu/dataset/183/communities+and+crime), UCI Machine Learning Repository.
